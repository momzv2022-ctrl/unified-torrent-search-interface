Set up your own search

This page hands you one file and a password. You paste them into a free Cloudflare account and you have your own search across several public torrent indexes, at a web address only you know. No terminal, no GitHub account, and it works on a phone.

1 · Your key

Made just now, in this browser, from your device's own random numbers. It has not been sent anywhere and nobody else has it — including us.

Your web address is the other half, and this page cannot work it out: it is name.your-account.workers.dev, Cloudflare picks the account part and adds words of its own to the name. It shows you the finished thing when you deploy — step 3 has a box to paste it into.

Save it somewhere now. Your password manager, your notes app, anywhere you will still have it next week. You will need it every time you point an app at your search.

Lost it later? It is not gone. The key is written into the file you are about to copy, so it will be sitting in your own Worker's code — open the Worker in Cloudflare, press Edit code, and read the line near the top that starts const API_KEY. That is also why this page does not put your key in its own web address: a bookmark that contains a password is a password you can leak by sharing a link.

Your search, ready to run:

curl -H "X-API-Key: YOUR-KEY" \
  "https://your-address.workers.dev/api/v1/search?q=big+buck+bunny&limit=5"

Two more addresses worth knowing. /healthz tells you which indexes are answering and which are failing, and needs no key. /api/v1/engines?probe=1 tries every index once from your Worker and reports what came back — that is the honest answer to "which of these actually work for me", because it depends on your Worker's network and not on the software.

What this is, and is not

It doesAsk several public indexes the same question, merge the answers, and hand back names, sizes, swarm counts and magnet: links.
It does notHost, store, or transfer any file. It is not a BitTorrent client and it downloads nothing. The links go to whatever torrent app you already have.
It keepsNo search log. Cloudflare's request logging is switched off in this file, on purpose, so your queries are not written into a durable log you would then have to trust.
It is notAnonymity. The indexes see the query, your network carries it, and on this setup Cloudflare is your network and can see the traffic. "No log kept here" is a true statement about logging and nothing more.

Some things it is good at

Linux and BSD installation images, Internet Archive material, public-domain film, Creative Commons music and video, game mods, and the large scientific and open datasets that are distributed over BitTorrent because it is the cheapest way to move a terabyte. The examples on this page are Big Buck Bunny and Sintel, both released by the Blender Foundation under Creative Commons, and Ubuntu.
